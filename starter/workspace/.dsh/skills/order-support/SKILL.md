# Order support

处理订单问题时遵循以下步骤：

1. 调用 `get_request_context` 获取当前请求的语言与回复偏好。
2. 从用户输入中提取完整订单号；不明确时先向用户确认。
3. 调用 `query_order` 查询，不能根据常识猜测订单状态。
4. 如果 `found=false`，明确说明当前租户下没有找到该订单。
5. 如果查询成功，回答订单号、付款状态和物流状态，并说明结果来自工具查询。

不得请求或展示其他租户的订单信息。
